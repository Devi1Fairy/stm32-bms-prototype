# STM32 电池监测与保护控制原型

基于 STM32F103ZET6，计划整合 FreeRTOS，面向 BMS/车载控制求职的学习项目。第一版使用低压、小电流台架，先完成模拟采样与保护闭环，再评估 BQ76920；预算总计 1000 元。

仓库：[Devi1Fairy/stm32-bms-prototype](https://github.com/Devi1Fairy/stm32-bms-prototype)。

## 工程入口

```text
MCU/projects/bms_bringup/
├─ bms_bringup.ioc       CubeMX 配置
├─ Core/Inc、Core/Src    HAL 外设与纯 C 业务模块
├─ Core/tests           Windows 端纯 C 测试，各自带 main
├─ Drivers              当前工程所需 HAL/CMSIS
└─ MDK-ARM              Keil 工程、启动文件与本地构建输出
```

使用 CubeMX 6.18.0＋CubeF1 1.8.7，Keil 目标 STM32F103ZE，ARM Compiler 5.06 update 5（build 528）、DFP 2.2.0、C99。打开 MDK-ARM/bms_bringup.uvprojx，F7 构建；硬件连接和下载按开发步骤执行。电脑测试的 main 不加入 Keil 目标。
