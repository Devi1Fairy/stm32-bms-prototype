# STM32 电池监测与保护控制原型

基于STM32F103ZET6、HAL和FreeRTOS的低压学习原型，使用电位器模拟单体电压、NTC估算温度、INA226采集真实负载电流，通过状态机控制MOS负载开关，并使用经典CAN和UART进行控制与监测。

仓库：[Devi1Fairy/stm32-bms-prototype](https://github.com/Devi1Fairy/stm32-bms-prototype)。

## 已实现的功能

- 电压、温度与电流记录包含数值、来源、有效标志和采样时间；显示滤波与保护输入分开处理。
- 纯C保护检查覆盖过压、欠压、过温、双向过流、采样无效和超时。
- 四状态控制框架包含自检、待机、运行、故障锁定；自检通过目前使用演示常量，硬件自检尚未实现。
- 故障撤销负载许可并锁存；满足恢复回差与连续稳定时间后，仍需CLEAR回待机、START再运行。
- FreeRTOS业务任务负责采样/保护/MOS，通信任务负责UART与CAN，心跳任务独立运行；完整报告通过1项邮箱按值复制，普通命令使用8项队列，STOP独立保留，入队失败请求停止。
- INA226只在新转换成功时刷新电流时间戳；读取失败标记无效，无新转换保留旧记录。
- 经典CAN使用500 kbit/s标准帧；UART接收单字符指令并输出状态与诊断日志。

控制100 ms、UART日志200 ms、CAN周期报告1000 ms、心跳翻转500 ms均为配置值，尚未测量端到端最坏响应时间。

## 台架与主要接线

首版使用台式电源与电阻负载，不连接真实电池组。逻辑供电3.3 V，负载电源5 V；正常负载100 Ω/5 W，过流演示使用47 Ω/10 W。INA226分流电阻印字R100，按标称0.100 Ω换算。

| STM32引脚 | 用途 |
| --- | --- |
| PC0 / ADC1_IN10 | 电位器输入，映射第一节模拟单体电压 |
| PC1 / ADC1_IN11 | NTC模块AO |
| PB6 / PB7 | I2C1 SCL / SDA，100 kHz |
| PB8 / PB9 | CAN RX / TX，外接SN65HVD230 |
| PB10 | LOAD_EN，高电平使能MOS |
| PB5 / PB0 / PB1 | 心跳 / 运行 / 故障指示LED，低电平亮 |

功率电流路径：

```text
电源正极 → MOS DC+ / OUT+
         → INA226 IN+ → 板上R100 → INA226 IN−
         → 负载电阻 → MOS OUT− → 板上MOS开关 → MOS DC− → 电源负极
```

INA226 VBS接自身IN−；INA226 GND、STM32 GND与电源负极建立共同参考。IN−是正极回路节点，OUT−是受控返回端，均不额外接地。新MOS控制端使用高电平“＋”与信号GND，低电平“－”悬空；控制“＋”到信号GND保留10 kΩ下拉。详细接线与改线顺序见[开发步骤](docs/开发步骤.md#ina226-current-diagnostic-20261027)。

## 控制与通信协议

UART：USART1，115200、8N1，普通文本发送大写字符。

| 字符 | 操作 |
| --- | --- |
| S / T | 启动 / 停止 |
| C | 满足恢复条件后清除故障，返回待机 |
| P / R | 暂停 / 恢复采样更新，保护和通信继续运行 |
| D | UART实验开关：切换通信任务每轮延迟1000 ms，复位默认关闭 |

CAN：标准数据帧，500 kbit/s。

| ID | 长度 | 内容 |
| --- | --- | --- |
| 0x201 | 1 | 01启动、02停止、03清故障、04查询 |
| 0x301 | 8 | 状态、负载许可、清除许可、序号、活动故障位图 |
| 0x302 | 8 | 第一节电压mV、估算温度0.1℃、电流mA、有效位、来源 |

0x302前三个量各占2字节，低字节先发；温度与电流为有符号16位数。第6字节的bit0/1/2表示电压/温度/电流新鲜有效；第7字节每两位依次表示三个量的来源。

若电流为48 mA且各项正常，电流字节为`30 00`、有效位`07`、来源`3A`。这是协议示例，不是实测报文记录。无效字段使用零占位，解释时同时检查有效位。0x301上报活动故障，历史锁存通过UART的`latched`或Watch观察。

## 构建与演示

工具：CubeMX 6.18.0、CubeF1 1.8.7、Keil 5、ARM Compiler 5.06 update 5、STM32F1xx_DFP 2.2.0，C99。

1. 打开`MCU/projects/bms_bringup/MDK-ARM/bms_bringup.uvprojx`并Rebuild。
2. 使用SWD下载；板级供电、ST-LINK及外设接线按[开发步骤](docs/开发步骤.md)确认。
3. 电位器居中、NTC正常，正常输入下上电后进入待机，发送S或CAN 01启动。
4. 按[演示版验收与复现流程](docs/开发步骤.md#demo-closeout-20261028)查看正常测量、故障关断及恢复清除。录像脚本保留为可选参考，当前不要求录制。

`Core/tests`中的测试各自带main，不加入Keil固件目标。主机端GCC测试方法见[测试记录](docs/测试记录.md#host-commands)。

## 范围与后续阶段

第一节电压为电位器映射的2800～4400 mV，第2、3节目前固定模拟3800 mV；没有完成真实三串采样。NTC使用暂定10 kΩ/B3950模型，未标定。INA226电流尚未校准，80 mA触发/60 mA恢复只作为台架演示参数。

IWDG、DMA、SPI故障存储、BQ76920、自制AFE子板、SOC、均衡、Bootloader及电机控制尚未实现，后续按需求推进。
