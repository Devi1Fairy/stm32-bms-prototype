## 本步目标和边界

新增 Bms_CheckTemperature()，对一路温度数据返回输入错误、数据无效、超时、正常、过温五种结果。

value 与过温阈值都使用 0.1℃，例如 250 表示 25.0℃，-50 表示 -5.0℃。负温度与零温度可以有效，不能复用负电压无效的数值规则。

本步只比较温度与过温阈值，并复用已有时效检查。NTC/ADC 换算、传感器测量范围、断线识别、低温保护、滤波、滞回、故障锁存及负载控制均未在本步实现。

测量范围和实际有效性将由采样端检查并设置 valid；本函数信任该标志，并检查来源是否为 NONE。当前所有测量均由软件构造，不能把本函数通过当作传感器校验通过。

60.0℃ 和 500 ms 只是测试参数，不是实物电池的保护配置。温度拥有独立时间戳和超时参数，之后按实际采样来源的刷新周期确定；重复上报或电压更新均不能刷新旧温度的时间戳。

## 第一步：添加类型和声明

在 Core/Inc/bms_protection.h 最后的 #endif 前添加，保留已有类型和声明：

```c
/* 一路温度数据的检查结果；只有 NORMAL 表示本项检查通过。 */
typedef enum
{
    BMS_TEMP_INPUT_ERROR = 0, /* 指针或超时参数错误 */
    BMS_TEMP_DATA_INVALID,    /* 测量数据未被标记为有效，或没有来源 */
    BMS_TEMP_TIMEOUT,         /* 数据已经过期 */
    BMS_TEMP_NORMAL,          /* 数据有效、未过期，且未达到过温阈值 */
    BMS_TEMP_OVER_LIMIT       /* 达到或超过过温阈值 */
} BmsTemperatureResult;

/*
 * 检查一路温度数据。
 * temperature：温度测量对象，value 的单位必须是 0.1℃。
 * over_temp_dC：过温阈值，单位 0.1℃；600 表示 60.0℃。
 * now_ms、max_age_ms：当前毫秒计数与允许的最大数据年龄。
 * 负温度可以有效，阈值也可以为零或负数。
 * 实际测量范围由采样端检查并设置 valid，本函数读取该标志。
 */
BmsTemperatureResult Bms_CheckTemperature(
    const BmsMeasurement *temperature,
    int32_t over_temp_dC,
    uint32_t now_ms,
    uint32_t max_age_ms);
```

只有 BMS_TEMP_NORMAL 表示本项检查通过。NORMAL 不表示全部电池保护已经通过，也不表示温度满足尚未实现的低温等条件。

## 第二步：添加函数实现

在 Core/Src/bms_protection.c 的现有函数后添加：

```c
BmsTemperatureResult Bms_CheckTemperature(
    const BmsMeasurement *temperature,
    int32_t over_temp_dC,
    uint32_t now_ms,
    uint32_t max_age_ms)
{
    BmsSampleStatus sample_status;

    /* 先区分调用参数错误与测量数据本身无效。 */
    if (temperature == NULL || max_age_ms == 0u)
    {
        return BMS_TEMP_INPUT_ERROR;
    }

    /* 复用时效检查，避免每种保护都重写时间差计算。 */
    sample_status = Bms_CheckSampleFreshness(
        temperature, now_ms, max_age_ms);

    if (sample_status == BMS_SAMPLE_INVALID)
    {
        return BMS_TEMP_DATA_INVALID;
    }

    if (sample_status == BMS_SAMPLE_TIMEOUT)
    {
        /* 旧温度值不能用于报告当前过温。 */
        return BMS_TEMP_TIMEOUT;
    }

    /*
     * 温度与阈值都使用 0.1℃，可以直接比较整数。
     * 达到阈值就触发，包含刚好相等的情况。
     */
    if (temperature->value >= over_temp_dC)
    {
        return BMS_TEMP_OVER_LIMIT;
    }

    return BMS_TEMP_NORMAL;
}
```

指针和超时参数先检查，因此调用错误与测量质量问题能分开报告。随后调用 Bms_CheckSampleFreshness，已有的无符号时间差处理可以直接复用。

过温判断包含相等边界。over_temp_dC 不强制为正，零或负数也是有含义的摄氏温度阈值；实际项目配置以后按应用与电池要求确定。

## 第三步：新建测试

新建 Core/tests/test_bms_temperature.c：

```c
#include <assert.h>
#include <stdio.h>
#include "bms_protection.h"

int main(void)
{
    BmsMeasurement temperature = {0};

    /* 60.0℃ 和 500 ms 仅为软件测试参数，实物配置尚未确定。 */
    const int32_t over_temp_dC = 600;
    const uint32_t now_ms = 1499u;
    const uint32_t max_age_ms = 500u;

    temperature.timestamp_ms = 1000u;
    temperature.valid = 1u;
    temperature.source = BMS_SOURCE_SIMULATED;

    /* 1：25.0℃，正常。 */
    temperature.value = 250;
    assert(Bms_CheckTemperature(
        &temperature, over_temp_dC, now_ms, max_age_ms)
        == BMS_TEMP_NORMAL);

    /* 2：59.9℃，比阈值低0.1℃。 */
    temperature.value = 599;
    assert(Bms_CheckTemperature(
        &temperature, over_temp_dC, now_ms, max_age_ms)
        == BMS_TEMP_NORMAL);

    /* 3：60.0℃，刚好达到阈值。 */
    temperature.value = 600;
    assert(Bms_CheckTemperature(
        &temperature, over_temp_dC, now_ms, max_age_ms)
        == BMS_TEMP_OVER_LIMIT);

    /* 4：65.0℃，超过阈值。 */
    temperature.value = 650;
    assert(Bms_CheckTemperature(
        &temperature, over_temp_dC, now_ms, max_age_ms)
        == BMS_TEMP_OVER_LIMIT);

    /* 5：-5.0℃可以是有效温度，不触发本项过温。 */
    temperature.value = -50;
    assert(Bms_CheckTemperature(
        &temperature, over_temp_dC, now_ms, max_age_ms)
        == BMS_TEMP_NORMAL);

    /* 6：有效的0℃也不应被误判为无效。 */
    temperature.value = 0;
    assert(Bms_CheckTemperature(
        &temperature, over_temp_dC, now_ms, max_age_ms)
        == BMS_TEMP_NORMAL);

    /* 7：数值看起来正常，但标志无效。 */
    temperature.value = 250;
    temperature.valid = 0u;
    assert(Bms_CheckTemperature(
        &temperature, over_temp_dC, now_ms, max_age_ms)
        == BMS_TEMP_DATA_INVALID);
    temperature.valid = 1u;

    /* 8：没有数据来源。 */
    temperature.source = BMS_SOURCE_NONE;
    assert(Bms_CheckTemperature(
        &temperature, over_temp_dC, now_ms, max_age_ms)
        == BMS_TEMP_DATA_INVALID);
    temperature.source = BMS_SOURCE_SIMULATED;

    /* 9：年龄达到500 ms，温度数值正常也应报告超时。 */
    temperature.timestamp_ms = 999u;
    assert(Bms_CheckTemperature(
        &temperature, over_temp_dC, now_ms, max_age_ms)
        == BMS_TEMP_TIMEOUT);

    /* 10：旧温度偏高，也只报告超时。 */
    temperature.value = 650;
    assert(Bms_CheckTemperature(
        &temperature, over_temp_dC, now_ms, max_age_ms)
        == BMS_TEMP_TIMEOUT);
    temperature.timestamp_ms = 1000u;
    temperature.value = 250;

    /* 11：空指针属于调用参数错误。 */
    assert(Bms_CheckTemperature(
        NULL, over_temp_dC, now_ms, max_age_ms)
        == BMS_TEMP_INPUT_ERROR);

    /* 12：超时参数为0，属于调用参数错误。 */
    assert(Bms_CheckTemperature(
        &temperature, over_temp_dC, now_ms, 0u)
        == BMS_TEMP_INPUT_ERROR);

    /* 13：阈值可以是0℃；-0.1℃尚未达到它。 */
    temperature.value = -1;
    assert(Bms_CheckTemperature(
        &temperature, 0, now_ms, max_age_ms)
        == BMS_TEMP_NORMAL);

    /* 14：阈值为0℃时，0℃刚好触发。 */
    temperature.value = 0;
    assert(Bms_CheckTemperature(
        &temperature, 0, now_ms, max_age_ms)
        == BMS_TEMP_OVER_LIMIT);

    /* 15：阈值可以为负；-6.0℃低于-5.0℃。 */
    temperature.value = -60;
    assert(Bms_CheckTemperature(
        &temperature, -50, now_ms, max_age_ms)
        == BMS_TEMP_NORMAL);

    /* 16：负阈值也包含相等边界。 */
    temperature.value = -50;
    assert(Bms_CheckTemperature(
        &temperature, -50, now_ms, max_age_ms)
        == BMS_TEMP_OVER_LIMIT);

    /* 17：计数回绕后年龄为499 ms，仍未超时。 */
    temperature.value = 250;
    temperature.timestamp_ms = UINT32_MAX - 99u;
    assert(Bms_CheckTemperature(
        &temperature, over_temp_dC, 399u, max_age_ms)
        == BMS_TEMP_NORMAL);

    /* 18：计数回绕后年龄为500 ms，刚好超时。 */
    assert(Bms_CheckTemperature(
        &temperature, over_temp_dC, 400u, max_age_ms)
        == BMS_TEMP_TIMEOUT);

    puts("18 temperature tests passed.");
    return 0;
}
```

18 项断言覆盖正常值、过温前后与边界、负温度和零温度、有效标志与来源、超时优先、参数错误、零及负阈值、计数回绕。

新测试有自己的 main()，只用于电脑，不加入 Keil MCU 目标。
