## 本步范围与接口约定

状态机回答的是：当前处于什么阶段、能否启动、是否需要锁定，以及是否允许负载工作。保护模块回答的是：本轮检查发现什么故障。两者职责不同，状态机不重新比较测量阈值。

| 状态 | 作用 | load_enabled |
| --- | --- | --- |
| SELF_TEST | 等待自检通过 | 0 |
| STANDBY | 等待新的启动指令 | 0 |
| RUN | 允许运行，持续检查故障 | 1 |
| FAULT_LOCK | 记录故障，等待满足条件后清除 | 0 |

| 条件 | 转换 |
| --- | --- |
| 任一活动故障，不论当前状态及指令 | FAULT_LOCK，并累计故障 |
| SELF_TEST，自检通过且无故障 | STANDBY |
| STANDBY，新的 START、自检通过且无故障 | RUN |
| RUN，STOP 且无故障 | STANDBY |
| FAULT_LOCK，仅数值恢复 | 继续锁定 |
| FAULT_LOCK，CLEAR、自检通过、恢复许可为1且无活动故障 | STANDBY，清除锁定记录 |

本轮活动故障优先于指令；每轮最多执行一次状态转换。自检通过的同一轮即使收到 START，也只进入待机；CLEAR 只回待机，另发一次 START 才启动。

本步只实现基本转换与锁定。self_test_passed 由后续自检模块提供，clear_allowed 由后续恢复条件模块提供；测试先手动填写这两个标志。真实自检内容、启动等待期限、恢复回差和暂定 2 s 稳定时间尚未实现，不能把 clear_allowed 固定为1用于真实控制。

self_test_passed 是启动自检结论；运行期健康异常须通过 active_faults 报告。当前数据有效性与新鲜度由已有检查函数负责，每轮完成检查并汇总后再交给状态机，不能以未检查的零故障值代替真实结果。

load_enabled 是软件输出许可，并非已经驱动 GPIO，也不代表检测到了实际负载状态。后续控制模块会将许可映射为默认关闭的硬件输出。

## 第一步：新建状态机头文件

新建 Core/Inc/bms_state_machine.h：

```c
#ifndef BMS_STATE_MACHINE_H
#define BMS_STATE_MACHINE_H

#include "bms_protection.h"

/* 当前控制阶段；上电初始化后先进入自检。 */
typedef enum
{
    BMS_STATE_SELF_TEST = 0, /* 等待自检通过，负载关闭 */
    BMS_STATE_STANDBY,       /* 已准备好，等待启动指令 */
    BMS_STATE_RUN,           /* 允许运行 */
    BMS_STATE_FAULT_LOCK     /* 故障锁定，等待满足条件后清除 */
} BmsState;

/* 每次处理一个指令；没有新指令时填写 NONE。 */
typedef enum
{
    BMS_CMD_NONE = 0,
    BMS_CMD_START,
    BMS_CMD_STOP,
    BMS_CMD_CLEAR
} BmsCommand;

/* 状态机保存的运行记录，需要在多次调用之间保留。 */
typedef struct
{
    BmsState state;
    uint32_t latched_faults; /* 锁定期间累计出现过的故障 */
    uint8_t load_enabled;   /* 1：软件允许负载工作；尚未操作 GPIO */
} BmsStateMachine;

/* 本轮输入；测量检查和恢复条件检查由外部提供。 */
typedef struct
{
    uint32_t active_faults;   /* 本轮 Bms_CombineFaults() 的结果 */
    BmsCommand command;      /* 本轮新收到的指令 */
    uint8_t self_test_passed; /* 1：自检已通过；0：尚未通过 */
    uint8_t clear_allowed;    /* 1：恢复条件已满足；0：禁止清除 */
} BmsControlInput;

/* 上电时调用一次，或测试中模拟复位时调用。 */
void Bms_StateMachineInit(BmsStateMachine *machine);

/*
 * 周期调用，即使没有指令也要检查故障。
 * 本函数只更新状态和输出许可，不操作真实负载。
 */
void Bms_StateMachineStep(
    BmsStateMachine *machine,
    const BmsControlInput *input);

#endif
```

BmsStateMachine 保存跨多轮保留的状态；BmsControlInput 保存本轮输入，两者不要混在一起。每轮活动故障可以消失，但锁定故障只有 CLEAR 成功或重新初始化才会清零。

command 表示一次新指令。调用方应消费后将下一轮指令设为 NONE，只有收到另一条指令时才重新填写；状态机不自行保存或排队，CAN 命令解析和队列留待后续实现。

## 第二步：新建状态机源文件

新建 Core/Src/bms_state_machine.c：

```c
#include <stddef.h>
#include "bms_state_machine.h"

void Bms_StateMachineInit(BmsStateMachine *machine)
{
    if (machine == NULL)
    {
        return;
    }

    machine->state = BMS_STATE_SELF_TEST;
    machine->latched_faults = BMS_FAULT_NONE;
    machine->load_enabled = 0u;
}

void Bms_StateMachineStep(
    BmsStateMachine *machine,
    const BmsControlInput *input)
{
    if (machine == NULL)
    {
        return;
    }

    /* 先关闭软件许可，只有最后确认处于 RUN 才重新置为1。 */
    machine->load_enabled = 0u;

    if (input == NULL)
    {
        machine->state = BMS_STATE_FAULT_LOCK;
        machine->latched_faults |= BMS_FAULT_INPUT_ERROR;
        return;
    }

    /* 故障优先于所有指令，包括 STOP 和 CLEAR。 */
    if (input->active_faults != BMS_FAULT_NONE)
    {
        machine->state = BMS_STATE_FAULT_LOCK;

        /* 累计故障，不覆盖锁定期间已经记录的其他故障。 */
        machine->latched_faults |= input->active_faults;
        return;
    }

    switch (machine->state)
    {
        case BMS_STATE_SELF_TEST:
            if (input->self_test_passed == 1u)
            {
                /* 本轮最多转到待机，不继续执行同一轮的 START。 */
                machine->state = BMS_STATE_STANDBY;
            }
            break;

        case BMS_STATE_STANDBY:
            if (input->command == BMS_CMD_START &&
                input->self_test_passed == 1u)
            {
                machine->state = BMS_STATE_RUN;
            }
            break;

        case BMS_STATE_RUN:
            if (input->command == BMS_CMD_STOP)
            {
                machine->state = BMS_STATE_STANDBY;
            }
            break;

        case BMS_STATE_FAULT_LOCK:
            /*
             * 到这里说明本轮没有活动故障。
             * 仍须收到 CLEAR、自检通过、恢复条件满足，才能解除锁定。
             */
            if (input->command == BMS_CMD_CLEAR &&
                input->self_test_passed == 1u &&
                input->clear_allowed == 1u)
            {
                machine->latched_faults = BMS_FAULT_NONE;
                machine->state = BMS_STATE_STANDBY;
            }
            break;

        default:
            /* 状态值不属于已定义的四种状态，关闭许可并锁定。 */
            machine->state = BMS_STATE_FAULT_LOCK;
            machine->latched_faults |= BMS_FAULT_INPUT_ERROR;
            break;
    }

    /* 输出许可由最终状态统一决定。 */
    if (machine->state == BMS_STATE_RUN)
    {
        machine->load_enabled = 1u;
    }
}
```

初始化函数只在上电时调用一次；测试可以再次调用来模拟复位。不要在主循环或每次 Step 前调用 Init，否则会清掉锁定记录。

Step 即使没有新指令也要周期执行，先接收最新保护结果，再处理指令。load_enabled 在函数入口被设为0，只有最后确认 RUN 才重新置为1；这只是变量更新，不代表函数内部已经执行了 GPIO 关闭。

输入指针为空或状态值异常会记录 INPUT_ERROR 并锁定。machine 指针为空则直接返回，无法更新任何状态；实际控制方必须始终持有有效的状态机对象，空指针返回不能当作真实硬件已关闭的证据。

## 第三步：新建电脑测试

新建 Core/tests/test_bms_state_machine.c：

```c
#include <assert.h>
#include <stddef.h>
#include <stdio.h>
#include "bms_state_machine.h"

/* 每个场景同时检查状态、锁定故障和负载许可。 */
static void CheckState(
    const BmsStateMachine *machine,
    BmsState expected_state,
    uint32_t expected_faults,
    uint8_t expected_load)
{
    assert(machine->state == expected_state);
    assert(machine->latched_faults == expected_faults);
    assert(machine->load_enabled == expected_load);
}

int main(void)
{
    BmsStateMachine machine;
    BmsControlInput input = {0};

    /* 1：模拟上电，先自检，负载关闭。 */
    Bms_StateMachineInit(&machine);
    CheckState(&machine, BMS_STATE_SELF_TEST, BMS_FAULT_NONE, 0u);

    /* 2：没有故障但自检尚未通过，继续等待。 */
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_SELF_TEST, BMS_FAULT_NONE, 0u);

    /* 3：自检未通过时收到启动指令，也不能运行。 */
    input.command = BMS_CMD_START;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_SELF_TEST, BMS_FAULT_NONE, 0u);

    /* 4：自检通过；同一轮的 START 不直接启动负载。 */
    input.self_test_passed = 1u;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_STANDBY, BMS_FAULT_NONE, 0u);

    /* 5：在待机时另发一次 START，进入运行。 */
    input.command = BMS_CMD_START;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_RUN, BMS_FAULT_NONE, 1u);

    /* 6：无新指令、无故障，保持运行。 */
    input.command = BMS_CMD_NONE;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_RUN, BMS_FAULT_NONE, 1u);

    /* 7：停止后回待机，关闭负载许可。 */
    input.command = BMS_CMD_STOP;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_STANDBY, BMS_FAULT_NONE, 0u);

    /* 8：待机收到 CLEAR 不会启动。 */
    input.command = BMS_CMD_CLEAR;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_STANDBY, BMS_FAULT_NONE, 0u);

    /* 9：启动指令与过压同时出现，故障优先。 */
    input.command = BMS_CMD_START;
    input.active_faults = BMS_FAULT_CELL_OV;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_FAULT_LOCK, BMS_FAULT_CELL_OV, 0u);

    /* 10：过压消失，但 START 不能解除锁定。 */
    input.active_faults = BMS_FAULT_NONE;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_FAULT_LOCK, BMS_FAULT_CELL_OV, 0u);

    /* 11：STOP 也不能解除锁定。 */
    input.command = BMS_CMD_STOP;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_FAULT_LOCK, BMS_FAULT_CELL_OV, 0u);

    /* 12：收到 CLEAR，但恢复条件未满足，保持锁定。 */
    input.command = BMS_CMD_CLEAR;
    input.clear_allowed = 0u;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_FAULT_LOCK, BMS_FAULT_CELL_OV, 0u);

    /* 13：锁定期间又出现过温，累计记录；故障优先于 CLEAR。 */
    input.clear_allowed = 1u;
    input.active_faults = BMS_FAULT_OVER_TEMP;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_FAULT_LOCK,
        BMS_FAULT_CELL_OV | BMS_FAULT_OVER_TEMP, 0u);

    /* 14：即使允许清除，自检未通过仍不能解除锁定。 */
    input.active_faults = BMS_FAULT_NONE;
    input.self_test_passed = 0u;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_FAULT_LOCK,
        BMS_FAULT_CELL_OV | BMS_FAULT_OVER_TEMP, 0u);

    /* 15：满足条件并收到 CLEAR，只回待机。 */
    input.self_test_passed = 1u;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_STANDBY, BMS_FAULT_NONE, 0u);

    /* 16：清除后没有新指令，不会自动运行。 */
    input.command = BMS_CMD_NONE;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_STANDBY, BMS_FAULT_NONE, 0u);

    /* 17：重新发送 START，才允许运行。 */
    input.command = BMS_CMD_START;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_RUN, BMS_FAULT_NONE, 1u);

    /* 18：运行中数据无效和超时，故障优先于 STOP。 */
    input.command = BMS_CMD_STOP;
    input.active_faults = BMS_FAULT_DATA_INVALID | BMS_FAULT_SAMPLE_TIMEOUT;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_FAULT_LOCK,
        BMS_FAULT_DATA_INVALID | BMS_FAULT_SAMPLE_TIMEOUT, 0u);

    /* 19：数据恢复、允许清除，CLEAR 返回待机。 */
    input.active_faults = BMS_FAULT_NONE;
    input.command = BMS_CMD_CLEAR;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_STANDBY, BMS_FAULT_NONE, 0u);

    /* 20：再次启动，为测试运行中输入错误做准备。 */
    input.command = BMS_CMD_START;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_RUN, BMS_FAULT_NONE, 1u);

    /* 21：输入指针为空，必须撤销负载许可并锁定。 */
    Bms_StateMachineStep(&machine, NULL);
    CheckState(&machine, BMS_STATE_FAULT_LOCK, BMS_FAULT_INPUT_ERROR, 0u);

    /* 22：异常状态值也必须进入锁定。 */
    Bms_StateMachineInit(&machine);
    machine.state = (BmsState)99;
    input.command = BMS_CMD_NONE;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_FAULT_LOCK, BMS_FAULT_INPUT_ERROR, 0u);

    /* 23：模拟复位，重新自检，不恢复原先运行状态。 */
    Bms_StateMachineInit(&machine);
    CheckState(&machine, BMS_STATE_SELF_TEST, BMS_FAULT_NONE, 0u);

    /* 24：自检阶段发生数据故障，也要锁定。 */
    input.self_test_passed = 0u;
    input.active_faults = BMS_FAULT_DATA_INVALID;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_FAULT_LOCK, BMS_FAULT_DATA_INVALID, 0u);

    /* 25：故障消失，但不能用 CLEAR 绕过尚未通过的自检。 */
    input.active_faults = BMS_FAULT_NONE;
    input.command = BMS_CMD_CLEAR;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_FAULT_LOCK, BMS_FAULT_DATA_INVALID, 0u);

    /* 26：自检通过后，允许清除并返回待机。 */
    input.self_test_passed = 1u;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_STANDBY, BMS_FAULT_NONE, 0u);

    /* 27：待机时若自检通过标志为0，也拒绝启动。 */
    input.self_test_passed = 0u;
    input.command = BMS_CMD_START;
    Bms_StateMachineStep(&machine, &input);
    CheckState(&machine, BMS_STATE_STANDBY, BMS_FAULT_NONE, 0u);

    puts("27 state machine scenarios passed.");
    return 0;
}
```

CheckState() 用三项 assert 同时验证状态、故障记录、软件输出许可。27 个场景共 81 项断言，覆盖启动、停止、锁定保持、故障累计、清除条件、命令与故障冲突、清除后不自动启动、自检约束、异常输入、异常状态和模拟复位。

测试中的 clear_allowed=1 仅表示“假定外部恢复检查已通过”，没有验证 2 s 或回差。两个相邻调用中的 START 在场景说明中代表两次独立收到的指令；实际命令消费规则仍需调用方遵守。
