## 1. 电位器接线前先确认引脚

用户确认电位器为裸件，随后更正“万用表还没到”。当前先用已知GND/3V3输入验证周期采样与串口输出；以下电阻识别流程留待表到货执行。已购候选RV0932-B103的实际脚序、是否带开关及脚距仍待实测，不按外观猜物理脚序。

裸电位器完全脱离其他电路、保持断电。万用表黑表笔接COM，红表笔接V/Ω测量孔，选择20 kΩ电阻量程或自动电阻挡。不要使用电流挡；电阻测量期间不给电位器或其相连电路供电。

随后识别：

1. 找到旋转时阻值基本保持约10 kΩ的一对端子，记为固定端A、B。
2. 找到分别与A、B之间阻值随旋转变化的端子，记为滑动端W。A-W增大时，B-W通常相应减小。
3. 若有额外端子，可能属于开关或机械结构，先按具体器件核对，不把它们随意接电源。
4. 记录A-B总阻值，以及W-A和W-B随旋转的变化；在器件或记录图中标清A/B/W后再接电。万用表当前未到，实测值与实际物理位置尚未提供，识别保持待实施。

确认A/B/W后，断开板卡及ST-LINK的USB供电，移除此前PC0到GND或3V3的直连，再接：

| 功能端 | 连接 |
| --- | --- |
| 固定端A | 开发板3V3 |
| 固定端B | 开发板GND |
| 滑动端W | PC0 |

A、B交换只改变旋转方向对应的电压变化方向。PC0的旧直连必须移除，避免滑动端被固定电平钳住。所有信号限定在同板3.3 V参考范围，电位器不使用5V供电。

测阻结束先移开表笔。通电后需要核对W对GND电压时，改用直流电压挡，黑表笔接GND、红表笔接W；电阻识别和带电电压测量分开进行。

面包板上三个电气节点分别落在不相通的连接组。若器件脚距不适配，应先做可靠的转接连接，不强行插入。实际脚位与接线验证完成前，电位器验收保持待完成。

## 2. 修改采样窗口

CubeMX打开现有.ioc，ADC1的规则转换Rank 1仍为Channel 10，将Sampling Time从当前1.5改为239.5 Cycles。其余保持：

- PC0/ADC1_IN10、单通道、软件触发、右对齐、关闭连续/扫描/间断转换。
- ADC时钟PCLK2/6=12 MHz。
- HSE/PLL与USART1保持现有参数，不启用ADC中断或DMA。
- 用户代码保留，保存生成。

生成后adc.c应为ADC_SAMPLETIME_239CYCLES_5。较高源阻抗需要足够时间给内部采样电容充电。10 kΩ电位器作为分压器时，中间位置的等效源阻抗约2.5 kΩ（忽略其他负载）；长采样窗口有利于本次慢变化输入实验。

100 ms是软件两次启动之间的间隔，239.5周期是每次内部采样窗口，不能混为一谈。12 MHz下，加上12.5个转换周期，单次理论约21 µs，程序还有其他开销。

## 3. 修改main.c用户区

### 引入格式化函数

在USER CODE BEGIN Includes区域追加，保留已有内容：

```c
#include <stdio.h>
```

本机ARMCC5的stdio.h在C99条件下声明snprintf，当前Keil已启用C99。snprintf只把文字写入内存，后面仍由HAL_UART_Transmit发送，不需要printf串口重定向。

### 周期与换算常量

替换PD用户区：

```c
/* USER CODE BEGIN PD */

#define LED_PERIOD_MS       500u
#define UART_PERIOD_MS      200u
#define ADC_PERIOD_MS       100u

/* 以下参考电压暂按3300mV估算，后续用实测值修正。 */
#define ADC_REFERENCE_MV    3300u
#define ADC_FULL_SCALE      4095u

/* USER CODE END PD */
```

### 变量

替换PV用户区。旧uart_message固定消息不再使用，应删除，避免无用变量或仍发送旧文本：

```c
/* USER CODE BEGIN PV */

static uint32_t led_last_ms = 0u;
static uint32_t uart_last_ms = 0u;
static uint32_t adc_last_ms = 0u;

/* 保留未采样标记；ADC首次成功读取后会更新。 */
static volatile uint32_t adc_raw = 0xFFFFFFFFu;
static volatile uint32_t adc_mv = 0u;

/* 先在内存中拼好一行文本，再通过UART发送。 */
static char uart_tx_buffer[64];

/* USER CODE END PV */
```

### 初始化

替换USER CODE BEGIN 2，删除上一版启动阶段的单次Start/Poll/Get/Stop，把转换移到周期分支；保留一次校准：

```c
/* USER CODE BEGIN 2 */

    /* 每次上电校准一次，周期读取时不用重复校准。 */
    if (HAL_ADCEx_Calibration_Start(&hadc1) != HAL_OK)
    {
        Error_Handler();
    }

    /* 三个动作分别计时。 */
    led_last_ms = HAL_GetTick();
    uart_last_ms = led_last_ms;
    adc_last_ms = led_last_ms;

/* USER CODE END 2 */
```

### 主循环

替换while用户区：

```c
/* USER CODE BEGIN WHILE */
    while (1)
    {
    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */
        uint32_t now_ms = HAL_GetTick();

        /* LED仍然每500毫秒翻转一次。 */
        if ((uint32_t)(now_ms - led_last_ms) >= LED_PERIOD_MS)
        {
            led_last_ms = now_ms;
            HAL_GPIO_TogglePin(LED_STATUS_GPIO_Port, LED_STATUS_Pin);
        }

        /* 每100毫秒启动并读取一次ADC。 */
        if ((uint32_t)(now_ms - adc_last_ms) >= ADC_PERIOD_MS)
        {
            adc_last_ms = now_ms;

            if (HAL_ADC_Start(&hadc1) != HAL_OK)
            {
                Error_Handler();
            }

            if (HAL_ADC_PollForConversion(&hadc1, 10u) != HAL_OK)
            {
                Error_Handler();
            }

            adc_raw = HAL_ADC_GetValue(&hadc1);

            if (HAL_ADC_Stop(&hadc1) != HAL_OK)
            {
                Error_Handler();
            }

            /* 采用整数换算为毫伏，加半个分母用于四舍五入。 */
            adc_mv = (adc_raw * ADC_REFERENCE_MV + ADC_FULL_SCALE / 2u)
                     / ADC_FULL_SCALE;
        }

        /* 每200毫秒打印最新读数，首次采样完成后才发送。 */
        if (((uint32_t)(now_ms - uart_last_ms) >= UART_PERIOD_MS)
            && (adc_raw <= ADC_FULL_SCALE))
        {
            uart_last_ms = now_ms;

            /* %lu与unsigned long配对，避免格式和参数类型不一致。 */
            int length = snprintf(uart_tx_buffer,
                                  sizeof(uart_tx_buffer),
                                  "ADC raw=%lu, input=%lu mV\r\n",
                                  (unsigned long)adc_raw,
                                  (unsigned long)adc_mv);

            /* 检查格式化是否失败，或者缓冲区是否不够。 */
            if ((length <= 0)
                || ((size_t)length >= sizeof(uart_tx_buffer)))
            {
                Error_Handler();
            }

            /* 只发送实际文本长度，不发送末尾的空字符。 */
            if (HAL_UART_Transmit(&huart1,
                                  (const uint8_t *)uart_tx_buffer,
                                  (uint16_t)length,
                                  100u) != HAL_OK)
            {
                Error_Handler();
            }
        }
    }
  /* USER CODE END 3 */
```

## 4. 代码理解与实际限制

- LED、ADC、UART各自保存上次执行时间。ADC更新数据，UART发送最近一次成功读到的数据；同轮ADC在UART前执行。
- ADC首次正常读取前，adc_raw为0xFFFFFFFF，发送条件阻止打印尚未初始化的测量。
- ADC转换仍采用轮询等待；UART仍阻塞发送。当前没有完整实时性保证或FreeRTOS任务，初始化/读取失败仍进入Error_Handler，作为外设验证策略。后续把失败改为无效、超时及故障处理。
- adc_mv按raw×3300/4095作满量程线性显示估算，加半个分母作四舍五入。最大乘积加舍入项约1352万，适合uint32_t；尚未做基准、电阻与ADC误差标定。
- 3300是参考电压假定值，不是已实测的VREF+。当前输入引脚电压与电池单体电压是不同测量对象，后续再实现量程映射或真实分压采样。
- snprintf缓冲区为64字节，返回值为本应生成的文本长度（不含末尾NUL）；负数表示失败，达到或超过容量表示截断。发送前检查，并只发送实际长度。
- %lu与unsigned long参数配对；const uint8_t*转换是将字符缓冲区交给按字节发送的HAL接口，数据内容不变。
- 使用整数毫伏显示，不引入浮点格式化。volatile只便于观察，不提供并发互斥。
- 到期执行一次，不集中补发延误周期，主循环耗时可能引入延后；USB/串口助手显示也有缓冲，不把目测行间隔作为精确计时。

例如raw为0、2048、4095时，按本步公式显示约0、1650、3300 mV。这是换算示例，不是已经测得的三点数据。

## 5. 验收顺序

### 软件链路先验收

在电位器引脚未确认时，可以沿用前一步分两次接PC0到同板GND/3V3的方法，换线前断开两路USB供电。新程序应连续打印，复位后能自动恢复，LED继续工作。

串口保持115200/8N1、文本模式、无流控、DTR/RTS关闭控制。F7编译、F8下载，退出断点暂停后观察。预期格式：

```text
ADC raw=2048, input=1650 mV
ADC raw=2047, input=1650 mV
```

以上只是格式与算法示例，不是实测日志。每约200 ms一行，数值随输入变化；默认没有滤波，少量跳动需要按实际值记录。

### 电位器链路再验收

引脚确认并接线后，从低端、中间、高端依次缓慢转动：

1. 原始值在低端接近0、高端接近4095，中间位置有连续变化。
2. 估算电压随原始值同方向变化，中间位置大致在参考范围中部；机械位置与精确电压关系取决于电位器特性。
3. 转动时无需复位，UART会持续更新，LED保持原节奏。
4. 有万用表时测W对GND的电压，记录与估算值的差异，后续再讨论标定；本步不承诺固定精度限。

反馈构建结果、低/中/高三个位置的实际串口行、是否转动即更新及LED现象。没有确认实物引脚或完成旋转测试时，只记录软件周期输出通过，不把它写成电位器已验收。
