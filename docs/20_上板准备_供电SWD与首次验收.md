## 当前程序究竟在做什么

```text
main()
  → HAL_Init()
  → SystemClock_Config()
  → MX_GPIO_Init()
  → while (1) 空循环
```

- HAL_Init()：初始化HAL基础设施，当前默认使用SysTick毫秒时基。
- SystemClock_Config()：当前使用内部HSI，标称系统与总线时钟8MHz，没有启用PLL。
- MX_GPIO_Init()：当前仅开启GPIOA时钟，没有配置用户LED输出。
- while(1)：重复执行用户逻辑的位置，当前为空；新增控制函数存在于工程，不等于已经被main()调用。

今天按 [最小工程逐项解释](05_最小工程逐项配置解释.md) 阅读这些函数，能指出它们在源码中的位置即可。上板第一轮先验证下载与断点，再分步增加LED、UART与采样。

## 板卡资料与适用条件

本页参考本地：

```text
手册/01_芯片与板卡/[野火]STM32F103ZET6核心板_双USB款_规格书V1.0.1.pdf
```

版本为2024/06 V1.0.1。重点是PDF第11～12页，第2.4节。PDF不上传Git，公开索引见 [本地手册索引](11_本地手册索引与阅读顺序.md)。

购物车只写F103ZET6核心板，收到实物后还需确认确为对应双USB款及匹配PCB。接线以实际板卡丝印、匹配原理图和调试器说明为准，下面是资料核对结果。

| 项目 | 规格书说明 | 到货后需要确认 |
| --- | --- | --- |
| USB Device | Type-C，可供电，同时连接MCU USB引脚；未实现USB功能时仅供电 | 具体接口位置与丝印 |
| USB转串口 | 另一个Type-C，可供电，板载CH340C | 实物是否具备、电脑能否识别COM口 |
| USART1 | 默认跳帽PA9接桥接芯片RXD，PA10接TXD | 跳帽与实际原理图一致 |
| BOOT | BOOT0、BOOT1默认接GND，从Flash启动 | 实物跳帽位置 |
| 电源灯 | D1为红色电源指示灯 | 位置、供电开关与上电现象 |
| 用户LED | D3、D4、D5为可控蓝色LED | GPIO与有效电平需查原理图，规格书未给出 |
| SWD | 五针接口，可接兼容SWD调试器 | 信号标签、排针方向与实际针脚位置 |

PA9是MCU USART1_TX，连接串口桥RX；PA10是MCU USART1_RX，连接串口桥TX，这是发送接接收的交叉连接。若实物匹配，可将板载串口桥用于后续UART日志；独立CH340模块留作备用，其TX/RX电平仍需单独确认。

## SWD信号核对表

下面给出功能对应关系，不指定排针物理顺序。不同ST-LINK产品的丝印和电源脚定义可能不同，实际接线前逐个核对。

| 核心板信号 | 调试器端对应功能 | 用途 |
| --- | --- | --- |
| SWDIO / PA13 | SWDIO；部分调试器标TMS | 调试数据 |
| SWCLK / PA14 | SWCLK；部分调试器标TCK | 调试时钟 |
| GND | GND | 共同电位参考 |
| NRST | NRST / RST，若引出 | 目标复位，便于复位及连接调试 |
| 3V3 | 仅在确认为目标电压参考输入时接VTref/VREF | 告知调试器目标逻辑电压 |

规格书2.4.2提到3V3对VREF，但不能据此把兼容ST-LINK上的“3.3V供电输出”当成VREF输入。本项目拟先由板卡规定的一个USB入口供电；调试器若只有3.3V/5V电源输出，不把它与已供电的板卡电源并接，待确认实际定义后决定供电脚接法。

先接核心板、调试器和供电，外围模块在后续步骤逐项加入。面包板可留在旁边，本轮没有必须插入面包板的器件。

## Keil入口准备

本机工程已有ST-LINK相关调试与Flash下载配置。本轮只读检查，未更改配置，也未连接实物。

1. 打开MDK-ARM/bms_bringup.uvprojx。
2. 找到Options for Target → Debug，认识ST-LINK调试器选择和Settings入口。
3. 到货后在Settings中确认使用SWD/SW模式，实际调试器与目标芯片可识别；尚未接设备时无目标信息不能算硬件连接失败。
4. 找到Utilities中的Flash下载设置，实际下载算法及连接效果到货后验收。
5. 保留已编译通过的芯片、编译器和时钟基线，上板配置修改逐项记录。

不需要为了等待硬件重装现有工具链。若到货后设备识别异常，再根据设备管理器与Keil实际提示判断是否需要驱动、接线或设置调整。

按实物匹配的资料核对供电、跳帽和SWD信号，再执行：

| 验收项 | 预期结果 | 当前状态 |
