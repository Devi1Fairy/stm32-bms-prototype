## 本步目标与方向约定

新增 Bms_CheckCurrent()，返回输入错误、数据无效、超时、正常、放电过流或充电过流。

沿用项目暂定约定：正电流为放电，负电流为充电。接入真实采样时必须校验电流方向。两个限流参数都为正数，分别表示各方向允许的大小，不要求两者有大小顺序关系。

| 测量值 | 测试限值 | 结果 |
| --- | --- | --- |
| +999 mA | 放电限值 1000 mA | 正常 |
| +1000 mA | 放电限值 1000 mA | 放电过流 |
| -499 mA | 充电限值 500 mA | 正常 |
| -500 mA | 充电限值 500 mA | 充电过流 |

1000 mA、500 mA 和 500 ms 只是软件测试参数，实物配置尚未确定。实际量程、断线、校准等有效性检查由采样端完成并设置 valid。

本步只输出测量检查结果，不执行充电控制、负载切换、故障锁存或 SOC 估算。充电方向判断用于解释有符号测量值，不表示新增充电控制功能。

## 第一步：添加类型和声明

在 Core/Inc/bms_protection.h 最后的 #endif 前添加：

```c
/* 一路电流的检查结果；只有 NORMAL 表示本项检查通过。 */
typedef enum
{
    BMS_CURRENT_INPUT_ERROR = 0,       /* 指针、限流参数或超时参数错误 */
    BMS_CURRENT_DATA_INVALID,          /* 数据未标记有效，或没有来源 */
    BMS_CURRENT_TIMEOUT,               /* 数据已经过期 */
    BMS_CURRENT_NORMAL,                /* 数据有效、未过期，且没有过流 */
    BMS_CURRENT_DISCHARGE_OVER_LIMIT,  /* 放电方向过流 */
    BMS_CURRENT_CHARGE_OVER_LIMIT      /* 充电方向过流 */
} BmsCurrentResult;

/*
 * 检查一路电流，value 的单位必须是 mA。
 * 程序约定：正数为放电，负数为充电；接实物后需校验方向。
 * discharge_limit_ma、charge_limit_ma 都填写正数，表示各方向的限值大小。
 * 例如限值分别为1000、500时，+1000和-500都触发对应过流。
 * 测量范围由采样端检查并设置 valid，本函数读取该标志。
 */
BmsCurrentResult Bms_CheckCurrent(
    const BmsMeasurement *current,
    int32_t discharge_limit_ma,
    int32_t charge_limit_ma,
    uint32_t now_ms,
    uint32_t max_age_ms);
```

## 第二步：添加实现

在 Core/Src/bms_protection.c 的现有函数后添加：

```c
BmsCurrentResult Bms_CheckCurrent(
    const BmsMeasurement *current,
    int32_t discharge_limit_ma,
    int32_t charge_limit_ma,
    uint32_t now_ms,
    uint32_t max_age_ms)
{
    BmsSampleStatus sample_status;

    /* 两个方向的限值都必须是正数，方向由电流值的正负表示。 */
    if (current == NULL ||
        discharge_limit_ma <= 0 ||
        charge_limit_ma <= 0 ||
        max_age_ms == 0u)
    {
        return BMS_CURRENT_INPUT_ERROR;
    }

    sample_status = Bms_CheckSampleFreshness(
        current, now_ms, max_age_ms);

    if (sample_status == BMS_SAMPLE_INVALID)
    {
        return BMS_CURRENT_DATA_INVALID;
    }

    if (sample_status == BMS_SAMPLE_TIMEOUT)
    {
        /* 旧电流不用于报告当前是否过流。 */
        return BMS_CURRENT_TIMEOUT;
    }

    /* 正方向达到限值，触发放电过流。 */
    if (current->value >= discharge_limit_ma)
    {
        return BMS_CURRENT_DISCHARGE_OVER_LIMIT;
    }

    /*
     * 将正数的充电限值变为负边界，再直接比较。
     * 不对测量值取绝对值，避免 INT32_MIN 取负时溢出。
     * charge_limit_ma 已确认是正数，因此对它取负可以安全表示。
     */
    if (current->value <= -charge_limit_ma)
    {
        return BMS_CURRENT_CHARGE_OVER_LIMIT;
    }

    return BMS_CURRENT_NORMAL;
}
```

检查顺序仍为参数、标志与来源、时间、数值边界。过期的正负大电流均先报告超时，保留实际问题类型。

INT32_MIN 的值为 -2147483648，取正后的 2147483648 超出 int32_t 范围。因此这里直接比较负边界，不对测量值取绝对值。charge_limit_ma 已经检查为正数，对它取负在 int32_t 中可以表示。

只有 BMS_CURRENT_NORMAL 表示本项通过。即使电流结果正常，仍需结合电压、温度以及后续状态机决定系统行为。

## 第三步：新建测试

新建 Core/tests/test_bms_current.c：

```c
#include <assert.h>
#include <stdio.h>
#include "bms_protection.h"

int main(void)
{
    BmsMeasurement current = {0};

    /* 仅为软件测试参数，实物限流值尚未确定。 */
    const int32_t discharge_limit_ma = 1000;
    const int32_t charge_limit_ma = 500;
    const uint32_t now_ms = 1499u;
    const uint32_t max_age_ms = 500u;

    current.timestamp_ms = 1000u;
    current.valid = 1u;
    current.source = BMS_SOURCE_SIMULATED;

    /* 1：有效零电流，正常。 */
    current.value = 0;
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, charge_limit_ma, now_ms, max_age_ms)
        == BMS_CURRENT_NORMAL);

    /* 2：放电电流比限值小1 mA。 */
    current.value = 999;
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, charge_limit_ma, now_ms, max_age_ms)
        == BMS_CURRENT_NORMAL);

    /* 3：刚好达到放电限值。 */
    current.value = 1000;
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, charge_limit_ma, now_ms, max_age_ms)
        == BMS_CURRENT_DISCHARGE_OVER_LIMIT);

    /* 4：超过放电限值。 */
    current.value = 1001;
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, charge_limit_ma, now_ms, max_age_ms)
        == BMS_CURRENT_DISCHARGE_OVER_LIMIT);

    /* 5：负电流可以有效，充电大小尚未达到500 mA。 */
    current.value = -499;
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, charge_limit_ma, now_ms, max_age_ms)
        == BMS_CURRENT_NORMAL);

    /* 6：刚好达到充电限值，对应负边界-500。 */
    current.value = -500;
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, charge_limit_ma, now_ms, max_age_ms)
        == BMS_CURRENT_CHARGE_OVER_LIMIT);

    /* 7：充电电流大小超过限值。 */
    current.value = -501;
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, charge_limit_ma, now_ms, max_age_ms)
        == BMS_CURRENT_CHARGE_OVER_LIMIT);

    /* 8：数值看起来正常，但标志无效。 */
    current.value = 100;
    current.valid = 0u;
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, charge_limit_ma, now_ms, max_age_ms)
        == BMS_CURRENT_DATA_INVALID);
    current.valid = 1u;

    /* 9：没有数据来源。 */
    current.source = BMS_SOURCE_NONE;
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, charge_limit_ma, now_ms, max_age_ms)
        == BMS_CURRENT_DATA_INVALID);
    current.source = BMS_SOURCE_SIMULATED;

    /* 10：年龄刚好500 ms，报告超时。 */
    current.timestamp_ms = 999u;
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, charge_limit_ma, now_ms, max_age_ms)
        == BMS_CURRENT_TIMEOUT);

    /* 11：旧值偏大，只报告超时。 */
    current.value = 1001;
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, charge_limit_ma, now_ms, max_age_ms)
        == BMS_CURRENT_TIMEOUT);

    /* 12：旧负值的大小偏大，也只报告超时。 */
    current.value = -501;
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, charge_limit_ma, now_ms, max_age_ms)
        == BMS_CURRENT_TIMEOUT);
    current.timestamp_ms = 1000u;
    current.value = 0;

    /* 13：空指针属于输入错误。 */
    assert(Bms_CheckCurrent(
        NULL, discharge_limit_ma, charge_limit_ma, now_ms, max_age_ms)
        == BMS_CURRENT_INPUT_ERROR);

    /* 14：放电限值为0，不接受。 */
    assert(Bms_CheckCurrent(
        &current, 0, charge_limit_ma, now_ms, max_age_ms)
        == BMS_CURRENT_INPUT_ERROR);

    /* 15：放电限值为负数，不接受。 */
    assert(Bms_CheckCurrent(
        &current, -1, charge_limit_ma, now_ms, max_age_ms)
        == BMS_CURRENT_INPUT_ERROR);

    /* 16：充电限值参数也必须填写正数。 */
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, 0, now_ms, max_age_ms)
        == BMS_CURRENT_INPUT_ERROR);

    /* 17：传入负数充电限值属于输入错误。 */
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, -1, now_ms, max_age_ms)
        == BMS_CURRENT_INPUT_ERROR);

    /* 18：超时参数为0，属于输入错误。 */
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, charge_limit_ma, now_ms, 0u)
        == BMS_CURRENT_INPUT_ERROR);

    /* 19：最大正整数，仍能正确比较。 */
    current.value = INT32_MAX;
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, charge_limit_ma, now_ms, max_age_ms)
        == BMS_CURRENT_DISCHARGE_OVER_LIMIT);

    /* 20：最小负整数，不取绝对值也能正确比较。 */
    current.value = INT32_MIN;
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, charge_limit_ma, now_ms, max_age_ms)
        == BMS_CURRENT_CHARGE_OVER_LIMIT);

    /* 21：计数回绕后年龄499 ms，仍正常。 */
    current.value = 0;
    current.timestamp_ms = UINT32_MAX - 99u;
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, charge_limit_ma, 399u, max_age_ms)
        == BMS_CURRENT_NORMAL);

    /* 22：计数回绕后年龄500 ms，刚好超时。 */
    assert(Bms_CheckCurrent(
        &current, discharge_limit_ma, charge_limit_ma, 400u, max_age_ms)
        == BMS_CURRENT_TIMEOUT);

    puts("22 current tests passed.");
    return 0;
}
```

极端整数用于检查 C 比较逻辑，不表示真实传感器具有该量程。这里的有效标志由测试构造，实际采样有效性需另行验证。
