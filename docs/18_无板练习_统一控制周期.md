## 本步目标与执行顺序

新增 Bms_ControllerStep()，接收一轮完整采样、一条新指令、自检结论、配置与当前时间，按顺序执行：

```text
校验保护与恢复配置
    → 正常电压、温度、电流检查
    → 汇总本轮 active_faults
    → 故障锁定期间更新 clear_allowed
    → 状态机处理故障与指令
    → 得到最终状态、锁定故障和软件负载许可
```

其他状态不累计恢复时间，清除成功后立即重置计时。每一轮使用同一采样快照和同一 now_ms，模块不修改测量值或时间戳，也不保存指令。

本步补齐保护配置与恢复配置的关系校验，恢复边界必须位于正常区间内且保留回差。错误配置立即作为 INPUT_ERROR 交给状态机锁定，不能等故障发生后才发现恢复配置不合适。

同一次运行中保持配置不变。const 指针仅限制通过该指针修改，不自动防止外部改动；更改配置前须重新开始恢复计时。实际自检仍由外部提供，当前测试手动传入其结论。

## 第一步：新建控制头文件

新建 Core/Inc/bms_controller.h：

```c
#ifndef BMS_CONTROLLER_H
#define BMS_CONTROLLER_H

#include "bms_state_machine.h"
#include "bms_recovery.h"

/* 正常保护阈值与恢复配置放在一起，便于统一校验。 */
typedef struct
{
    int32_t uv_threshold_mv;       /* 单体欠压触发值，单位mV */
    int32_t ov_threshold_mv;       /* 单体过压触发值，单位mV */
    int32_t over_temp_dC;          /* 过温触发值，单位0.1℃ */
    int32_t discharge_limit_ma;    /* 放电限值，填写正数，单位mA */
    int32_t charge_limit_ma;       /* 充电限值大小，填写正数，单位mA */
    uint32_t voltage_max_age_ms;
    uint32_t temperature_max_age_ms;
    uint32_t current_max_age_ms;
    BmsRecoveryConfig recovery;
} BmsControllerConfig;

/* 需要跨控制周期保留的记录。 */
typedef struct
{
    BmsStateMachine machine;
    BmsRecovery recovery;
    uint32_t active_faults;  /* 本轮保护检查结果 */
    uint8_t clear_allowed;  /* 仅在故障锁定期间可能为1 */
} BmsController;

/* 上电调用一次，不要每轮重新初始化。 */
void Bms_ControllerInit(BmsController *controller);

/*
 * 处理一轮完整采样和一条新指令。
 * 无新指令时传入 NONE；本函数不保存指令，也不刷新采样时间戳。
 * 配置在运行期间保持不变；修改前须重新开始恢复计时。
 */
void Bms_ControllerStep(
    BmsController *controller,
    const BmsSample *sample,
    const BmsControllerConfig *config,
    BmsCommand command,
    uint8_t self_test_passed,
    uint32_t now_ms);

#endif
```

BmsController 保存跨多轮的记录，BmsControllerConfig 保存阈值与时效参数。初始 active_faults 标记为 DATA_INVALID，表示首次检查未执行；初始化状态仍为 SELF_TEST，负载许可为0，锁定历史为0。

## 第二步：新建控制源文件

新建 Core/Src/bms_controller.c：

```c
#include <stddef.h>
#include "bms_controller.h"

/* static表示这个辅助函数只在本文件内部使用。 */
static uint8_t Bms_ControllerConfigIsValid(
    const BmsControllerConfig *config)
{
    const BmsRecoveryConfig *recovery;

    if (config == NULL)
    {
        return 0u;
    }

    recovery = &config->recovery;

    /* 先检查正常保护参数是否成立。 */
    if (config->uv_threshold_mv <= 0 ||
        config->ov_threshold_mv <= config->uv_threshold_mv ||
        config->discharge_limit_ma <= 0 ||
        config->charge_limit_ma <= 0 ||
        config->voltage_max_age_ms == 0u ||
        config->temperature_max_age_ms == 0u ||
        config->current_max_age_ms == 0u)
    {
        return 0u;
    }

    /* 恢复边界必须位于正常区间内，保留明确的回差。 */
    if (recovery->cell_min_mv <= config->uv_threshold_mv ||
        recovery->cell_max_mv >= config->ov_threshold_mv ||
        recovery->cell_min_mv >= recovery->cell_max_mv ||
        recovery->max_temperature_dC >= config->over_temp_dC ||
        recovery->discharge_limit_ma <= 0 ||
        recovery->discharge_limit_ma >= config->discharge_limit_ma ||
        recovery->charge_limit_ma <= 0 ||
        recovery->charge_limit_ma >= config->charge_limit_ma ||
        recovery->voltage_max_age_ms == 0u ||
        recovery->temperature_max_age_ms == 0u ||
        recovery->current_max_age_ms == 0u ||
        recovery->stable_time_ms == 0u)
    {
        return 0u;
    }

    return 1u;
}

void Bms_ControllerInit(BmsController *controller)
{
    if (controller == NULL)
    {
        return;
    }

    Bms_StateMachineInit(&controller->machine);
    Bms_RecoveryInit(&controller->recovery);

    /* 首次检查尚未执行，不把未知数据报告为正常。 */
    controller->active_faults = BMS_FAULT_DATA_INVALID;
    controller->clear_allowed = 0u;
}

void Bms_ControllerStep(
    BmsController *controller,
    const BmsSample *sample,
    const BmsControllerConfig *config,
    BmsCommand command,
    uint8_t self_test_passed,
    uint32_t now_ms)
{
    BmsVoltageReport voltage;
    BmsTemperatureResult temperature;
    BmsCurrentResult current;
    BmsControlInput input = {0};

    if (controller == NULL)
    {
        return;
    }

    input.command = command;
    input.self_test_passed = self_test_passed;

    /* 缺少采样对象或配置错误，立即交给状态机锁定。 */
    if (sample == NULL || Bms_ControllerConfigIsValid(config) == 0u)
    {
        controller->active_faults = BMS_FAULT_INPUT_ERROR;
        controller->clear_allowed = 0u;
        Bms_RecoveryInit(&controller->recovery);

        input.active_faults = controller->active_faults;
        Bms_StateMachineStep(&controller->machine, &input);
        return;
    }

    /* 1：使用正常保护阈值，检查同一轮采样和同一个当前时间。 */
    voltage = Bms_CheckPackVoltages(
        sample, config->uv_threshold_mv, config->ov_threshold_mv,
        now_ms, config->voltage_max_age_ms);

    temperature = Bms_CheckTemperature(
        &sample->temperature_dC, config->over_temp_dC,
        now_ms, config->temperature_max_age_ms);

    current = Bms_CheckCurrent(
        &sample->current_ma,
        config->discharge_limit_ma, config->charge_limit_ma,
        now_ms, config->current_max_age_ms);

    controller->active_faults = Bms_CombineFaults(
        &voltage, temperature, current);

    /* 2：只有已经处于故障锁定时，才累计恢复时间。 */
    controller->clear_allowed = 0u;

    if (controller->machine.state == BMS_STATE_FAULT_LOCK)
    {
        controller->clear_allowed = Bms_RecoveryUpdate(
            &controller->recovery, sample, &config->recovery,
            controller->active_faults, now_ms);
    }
    else
    {
        Bms_RecoveryInit(&controller->recovery);
    }

    /* 3：统一交给状态机决定下一状态和软件输出许可。 */
    input.active_faults = controller->active_faults;
    input.clear_allowed = controller->clear_allowed;
    Bms_StateMachineStep(&controller->machine, &input);

    /* 清除成功后立即丢弃计时，避免下次故障复用旧记录。 */
    if (controller->machine.state != BMS_STATE_FAULT_LOCK)
    {
        Bms_RecoveryInit(&controller->recovery);
        controller->clear_allowed = 0u;
    }
}
```

辅助校验函数用 static 限制在本文件内。保护要求0<欠压阈值<过压阈值、两个电流限值为正、超时非零；恢复要求电压区间更窄、过温恢复值更低、两个电流恢复限值更小、超时及稳定时间非零。

初始化只调用一次。Step即使没有新指令也要周期执行；调用方传 NONE 表示没有新事件。自检阶段和过早 CLEAR 的指令不会被内部缓存，也不会在未来自动重放。

控制器计算完恢复许可后调用状态机；若清除成功，状态已经是 STANDBY，马上重置恢复记录，并把对外 clear_allowed 设为0。许可只属于当前锁定周期，不复用到下一次故障。

空采样对象或错误配置会产生 INPUT_ERROR；非空对象中的 valid=0 则由正常保护得到 DATA_INVALID。这是调用参数错误与测量质量错误的区别。

#include <assert.h>
#include <stddef.h>
#include <stdio.h>
#include "bms_controller.h"

static unsigned int scenarios = 0u;

/* 测试假定取得了新采样，因此更新各通道的时间戳。 */
static void MakeHealthySample(BmsSample *sample, uint32_t now_ms)
{
    unsigned int i;

    for (i = 0u; i < BMS_CELL_COUNT; ++i)
    {
        sample->cell_mv[i].value = 3800;
        sample->cell_mv[i].timestamp_ms = now_ms;
        sample->cell_mv[i].valid = 1u;
        sample->cell_mv[i].source = BMS_SOURCE_SIMULATED;
    }

    sample->temperature_dC.value = 250;
    sample->temperature_dC.timestamp_ms = now_ms;
    sample->temperature_dC.valid = 1u;
    sample->temperature_dC.source = BMS_SOURCE_SIMULATED;

    sample->current_ma.value = 0;
    sample->current_ma.timestamp_ms = now_ms;
    sample->current_ma.valid = 1u;
    sample->current_ma.source = BMS_SOURCE_SIMULATED;
}

static void CheckController(
    const BmsController *controller,
    BmsState state,
    uint32_t active_faults,
    uint32_t latched_faults,
    uint8_t enabled,
    uint8_t clear_allowed)
{
    assert(controller->machine.state == state);
    assert(controller->active_faults == active_faults);
    assert(controller->machine.latched_faults == latched_faults);
    assert(controller->machine.load_enabled == enabled);
    assert(controller->clear_allowed == clear_allowed);
    ++scenarios;
}

int main(void)
{
    BmsController controller;
    BmsSample sample = {0};

    /* 仅为软件测试配置，单位与头文件中的字段说明一致。 */
    const BmsControllerConfig config = {
        3000, 4200, 600, 1000, 500,
        500u, 500u, 500u,
        {3200, 4100, 550, 800, 300, 500u, 500u, 500u, 2000u}
    };
    BmsControllerConfig bad_config;
    const uint32_t multiple_faults =
        BMS_FAULT_CELL_OV | BMS_FAULT_CELL_UV |
        BMS_FAULT_OVER_TEMP | BMS_FAULT_DISCHARGE_OC;

    /* 初始化尚未检查采样，但不会因此自动产生锁定记录。 */
    Bms_ControllerInit(&controller);
    CheckController(&controller, BMS_STATE_SELF_TEST,
        BMS_FAULT_DATA_INVALID, BMS_FAULT_NONE, 0u, 0u);

    /* 正常采样，自检未通过，继续等待。 */
    MakeHealthySample(&sample, 1000u);
    Bms_ControllerStep(&controller, &sample, &config,
        BMS_CMD_NONE, 0u, 1000u);
    CheckController(&controller, BMS_STATE_SELF_TEST, 0u, 0u, 0u, 0u);

    /* 自检通过的同一轮收到 START，只进入待机。 */
    MakeHealthySample(&sample, 1100u);
    Bms_ControllerStep(&controller, &sample, &config,
        BMS_CMD_START, 1u, 1100u);
    CheckController(&controller, BMS_STATE_STANDBY, 0u, 0u, 0u, 0u);

    MakeHealthySample(&sample, 1200u);
    Bms_ControllerStep(&controller, &sample, &config,
        BMS_CMD_START, 1u, 1200u);
    CheckController(&controller, BMS_STATE_RUN, 0u, 0u, 1u, 0u);

    MakeHealthySample(&sample, 1300u);
    Bms_ControllerStep(&controller, &sample, &config,
        BMS_CMD_STOP, 1u, 1300u);
    CheckController(&controller, BMS_STATE_STANDBY, 0u, 0u, 0u, 0u);

    MakeHealthySample(&sample, 1400u);
    Bms_ControllerStep(&controller, &sample, &config,
        BMS_CMD_START, 1u, 1400u);
    CheckController(&controller, BMS_STATE_RUN, 0u, 0u, 1u, 0u);

    /* 实际构造过压测量；同一轮的 STOP 不改变故障优先级。 */
    MakeHealthySample(&sample, 1500u);
    sample.cell_mv[0].value = 4200;
    Bms_ControllerStep(&controller, &sample, &config,
        BMS_CMD_STOP, 1u, 1500u);
    CheckController(&controller, BMS_STATE_FAULT_LOCK,
        BMS_FAULT_CELL_OV, BMS_FAULT_CELL_OV, 0u, 0u);

    /* 4150 mV不再触发过压，但尚未进入恢复区间。 */
    MakeHealthySample(&sample, 1600u);
    sample.cell_mv[0].value = 4150;
    Bms_ControllerStep(&controller, &sample, &config,
        BMS_CMD_CLEAR, 1u, 1600u);
    CheckController(&controller, BMS_STATE_FAULT_LOCK,
        0u, BMS_FAULT_CELL_OV, 0u, 0u);
    assert(controller.recovery.timing == 0u);

    /* 开始恢复计时；过早的 CLEAR 不会被保存。 */
    MakeHealthySample(&sample, 1700u);
    Bms_ControllerStep(&controller, &sample, &config,
        BMS_CMD_CLEAR, 1u, 1700u);
    CheckController(&controller, BMS_STATE_FAULT_LOCK,
        0u, BMS_FAULT_CELL_OV, 0u, 0u);
    assert(controller.recovery.stable_since_ms == 1700u);

    MakeHealthySample(&sample, 3699u);
    Bms_ControllerStep(&controller, &sample, &config,
        BMS_CMD_NONE, 1u, 3699u);
    CheckController(&controller, BMS_STATE_FAULT_LOCK,
        0u, BMS_FAULT_CELL_OV, 0u, 0u);

    /* 满2 s且没有新指令，仍然保持锁定。 */
    MakeHealthySample(&sample, 3700u);
    Bms_ControllerStep(&controller, &sample, &config,
        BMS_CMD_NONE, 1u, 3700u);
    CheckController(&controller, BMS_STATE_FAULT_LOCK,
        0u, BMS_FAULT_CELL_OV, 0u, 1u);

    MakeHealthySample(&sample, 3800u);
    Bms_ControllerStep(&controller, &sample, &config,
        BMS_CMD_CLEAR, 1u, 3800u);
    CheckController(&controller, BMS_STATE_STANDBY, 0u, 0u, 0u, 0u);
    assert(controller.recovery.timing == 0u);

    MakeHealthySample(&sample, 3900u);
    Bms_ControllerStep(&controller, &sample, &config,
        BMS_CMD_NONE, 1u, 3900u);
    CheckController(&controller, BMS_STATE_STANDBY, 0u, 0u, 0u, 0u);

    MakeHealthySample(&sample, 4000u);
    Bms_ControllerStep(&controller, &sample, &config,
        BMS_CMD_START, 1u, 4000u);
    CheckController(&controller, BMS_STATE_RUN, 0u, 0u, 1u, 0u);

    /* 多个测量故障同时出现，正常保护必须全部汇总。 */

    sample.cell_mv[0].value = 3000;
    sample.cell_mv[1].value = 4200;
    sample.temperature_dC.value = 600;
    sample.current_ma.value = 1000;
    Bms_ControllerStep(&controller, &sample, &config,
        BMS_CMD_NONE, 1u, 4100u);

    MakeHealthySample(&sample, 4200u);
    Bms_ControllerStep(&controller, &sample, &config,
        BMS_CMD_START, 1u, 4200u);

    sample.current_ma.valid = 0u;
    Bms_ControllerStep(&controller, &sample, &config,
        BMS_CMD_NONE, 1u, 5000u);
    CheckController(&controller, BMS_STATE_FAULT_LOCK,
        BMS_FAULT_DATA_INVALID,
        multiple_faults | BMS_FAULT_DATA_INVALID, 0u, 0u);

    MakeHealthySample(&sample, 5100u);
    Bms_ControllerStep(&controller, &sample, &config,
        BMS_CMD_NONE, 1u, 5100u);
    CheckController(&controller, BMS_STATE_FAULT_LOCK,

    /* 时间已满，但旧温度恰好超时，仍不能清除。 */

    sample.temperature_dC.timestamp_ms = 6600u;

31个场景通过 CheckController() 自动计数，每个场景检查状态、活动故障、锁定故障、软件负载许可及恢复许可五项；另有计时记录断言。

本测试通过测量值、valid和时间戳触发真实检查链，不直接把活动故障或恢复许可手填给状态机。自检结论仍为测试输入，不能写成实际自检已经完成。

关键序列如下：

| 时间/ms | 输入或操作 | 结果 |
| --- | --- | --- |
| 1200 | 新 START | RUN |
| 1500 | 第1节4200 mV且STOP | 过压锁定优先 |
| 1600 | 第1节4150 mV且CLEAR | 活动过压消失，恢复区间未满足，仍锁定 |
| 1700 | 恢复正常且CLEAR | 开始计时，拒绝过早清除 |
| 3699 | 正常，无指令 | 稳定1999 ms，不允许清除 |
| 3700 | 正常，无指令 | 许可为1，但继续锁定 |
| 3800 | 新 CLEAR | 返回待机，清计时 |
| 4000 | 新 START | 重新运行 |

后续序列覆盖多故障并存、无效和超时重新计时，以及错误配置阻止启动。MakeHealthySample() 只表示测试假定取得新采样；真实驱动不能通过刷新旧值的时间戳维持有效。
