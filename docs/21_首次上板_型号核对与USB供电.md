# 首次上板：型号核对与USB供电

日期：2026-10-17。用户已确认开发板到货，并反馈D1亮、D3/D4/D5蓝灯闪烁。后续照片已核对双USB布局、SWD标签和ST-LINK外壳针脚表；MCU完整丝印与PCB版本仍待确认。实际已用USB口未反馈，供电电压未测量；尚未下载或验证本项目固件。

## 第一步：识别实物

把开发板放在绝缘平面上，查看：

- 主芯片完整丝印是否为STM32F103ZET6。
- 板卡名称、PCB版本及USB接口数量和丝印。
- BOOT0、BOOT1跳帽及电源开关位置。
- SWD接口的信号标签。
- ST-LINK的型号与针脚丝印，先记录定义。

当前本地资料是野火双USB款规格书V1.0.1（2024/06）。它描述两个Type-C接口、板载CH340C、默认BOOT0与BOOT1接GND。实物若不匹配，需要先找到对应资料，不能直接套用排针顺序。

用户已提供开发板正面与ST-LINK标签照片，USB接口及SWD标签可辨认，下一步接线见[SWD接线与Keil识别](22_首次上板_SWD接线与Keil识别.md)。芯片完整丝印和PCB版本可在后续清晰照片或实物文字反馈中补齐。

## 第二步：确认入口后，单板USB供电

确认实物供电接口定义后：

1. 使用与接口匹配的USB线，通过板卡规定的一个USB入口连接电脑。
2. 若为规格书对应双USB款，USB Device和USB转串口口均可供电，首次选其中一个明确的接口。
3. 有电源开关时置于开启位置，观察电源指示灯。
4. 记录哪些灯亮、颜色及是否闪烁。
5. 若出现明显异常发热或异味，拔掉USB并记录现象。

这一轮只接板卡USB供电。ST-LINK、外接CH340、电位器、NTC和其他外围模块在后续步骤分别接入，便于逐项判断现象。

若接口或跳帽标签无法确认，先提供照片核对供电入口，再执行本节；不需要猜测3V3/5V排针位置或改动BOOT跳帽。

## 预期现象及意义

若实物匹配现有规格书，D1红色电源指示灯在供电及开关正常时应亮。它只能作为上电现象，不能证明自己的程序已运行；其他用户LED可能由预装程序控制。

当前项目尚未实现MCU USB功能。接USB Device口不出现新的COM口是可能的，不能据此判断板卡未工作；USB转串口接口通过板载CH340C枚举，驱动和设备识别后续另行检查。

首次上电后应反馈：

- 实际板型及PCB，或可辨认这些信息的照片。
- 使用哪个USB口，电源开关和跳帽状态。
- 哪些灯亮、颜色和闪烁情况。
- ST-LINK针脚定义照片。

## 下一步的验收目标

实物和供电核对完成后，再按实际调试器的定义连接SWD，验证Keil识别目标、下载程序和命中main()断点。具体针脚顺序及电源/参考脚接法依据实物决定。

本步不修改代码、CubeMX或Keil配置。实际GPIO和UART配置分别在后续小步骤完成。
